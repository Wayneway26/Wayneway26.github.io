A digital archive for 巫溪嫁花, an intangible-heritage embroidery tradition from Chongqing. 02 Engineering log

Notes from the parts that didn't go to plan.

  1. 2026.10

    Corrected a colour from a screenshot

    The BX-P-08 series renders on red. We had written down #cecece. When the source of truth is an image, the dataset should say so instead of guessing a hex value.

    data
  2. 2026.09

    Payments with no platform certificate

    Post-2024 merchant accounts only offer public-key mode over APIv3. Signature verification had to be written against the public key alone, with no certificate fallback to lean on.

    payments
  3. 2026.09

    One skill install, three clients

    Twenty research-writing skills installed once under ~/.agents/skills and symlinked into Copilot, Codex and Claude — audited first for remote-execution and prompt-injection patterns.

    tooling
  4. 2026.08

    A migration that kept its provenance

    Moved the 老绣 An-XX 纹样库 and 绣片数字库 image sets across, preserving every record's original folder path so a transcription can always be traced back to the scan it came from.

    archive
  5. 2026.08

    What down -v costs

    Rebuilt MySQL and Redis from nothing after a volume wipe took the seed data with it. Seed records now live in version control, next to the schema.

    infra

03 About

How I tend to work.

Most of the data I handle arrives second-hand — a spreadsheet exported from a scanner, a Word file attached to an email. The temptation is to tidy it into something plausible. I'd rather leave the gap visible and mark it as missing, because a placeholder that admits nothing is worse than an empty cell.

I also trust systems I can run over systems that describe themselves well. That bias shapes how I write agent code, how I review a dataset, and how I read a specification: first get it executing, then argue about it.

The rest of the time: long-form academic editing in Chinese, and a slow interest in typography and interface craft — which is why this page has no framework behind it.
