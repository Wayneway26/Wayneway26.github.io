# 魏亿恒的个人作品集

根据已发布的作品集页面重建。页面用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或构建。

- 修改经历、项目、技能和联系方式，编辑 `index.html`。邮箱在复制按钮和邮件链接各有一处。
- 修改排版、配色和响应式布局，编辑 `styles.css`。
- 修改移动端菜单、导航高亮、滚动动画或复制邮箱，编辑 `main.js`。

在仓库根目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，再打开 <http://127.0.0.1:8000/portfolio/>。

GitHub Pages 使用 **Deploy from a branch → main → / (root)**。推送到 `main` 后，GitHub Pages 会发布更新。线上地址为 <https://wayneway26.github.io/portfolio/>。

原站的履历、指标和项目地址按原文保留。页面从 Google Fonts 加载字体，并提供系统字体作为后备。
